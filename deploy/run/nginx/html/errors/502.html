502

上游服务不可用

Nginx 已启动，但无法从后端获得有效响应。通常是 API、前端开发服务或 MinIO 未运行。

  • 租户 API：tenant-api 监听 127.0.0.1:8443
  • 租户前端：tenant-web 开发服务 127.0.0.1:2001
  • 平台 API：platform-api 监听 127.0.0.1:9443
  • MinIO：127.0.0.1:9000（API）/ 9001（控制台）
  • PostgreSQL、Redis 异常也会导致 API 启动失败，请先检查依赖服务。
检查 API 健康 返回首页

运维提示：查看 logs/error.log、logs/minio_*_error.log 及后端进程日志。
