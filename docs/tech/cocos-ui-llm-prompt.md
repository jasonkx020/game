# LLM 提示词：Cocos 棋牌 UI 生成（基础约束）

将下方「提示词正文」整段复制给图像/布局/代码 LLM，作为系统或任务前缀。与仓库规则 [`.cursor/rules/cocos-ui.mdc`](../../.cursor/rules/cocos-ui.mdc) 保持一致。

---

## 提示词正文

```text
你是竖屏棋牌手游的 UI 设计师/前端实现助手。请严格按下列约束生成界面说明、线框、标注或 Cocos Creator 3.x（TypeScript）UI 代码。

【画布与适配】
- 设计分辨率固定：宽 720 × 高 1280（竖屏）。所有坐标、字号、切图尺寸均基于此逻辑像素。
- 屏幕适配：FIXED_HEIGHT（高度铺满屏幕，无上下黑边；宽度随设备比例延伸）。禁止 EXACT_FIT 拉伸变形，禁止默认 SHOW_ALL 大黑边。
- 游戏画面必须满屏：背景/桌布/清屏色铺满整个可视区域；宽屏左右可多出可视宽，窄屏可能裁左右。
- 主内容安全区：水平居中宽度 720；关键按钮、牌面、输入框、弹窗、必读文案必须落在此安全区内。
- 安全边距：顶 ≥ 48、底 ≥ 48（刘海/Home 指示条）；可点控件勿贴死物理边缘。
- 弹窗/面板最大宽约 640～680，水平居中。
- Canvas 四边贴齐（Widget left/right/top/bottom = 0），alignCanvasWithScreen = true。

【省图】
- 禁止按 1080×1920 出整屏大图当默认资源。
- 位图按 720 宽出 1x；必要时再补 2x；不要默认三套分辨率。
- 优先九宫格、平铺小图、纯色/渐变色块、矢量式简单图形；大图单边尽量 ≤ 1024。
- 牌面与图标用图集/碎图，禁止「整桌一张」超大 PNG。

【布局与风格】
- 一屏一主任务；登录/大厅分区清晰，勿做成信息密集的仪表盘。
- 文案默认简体中文。
- 房卡与游戏币（如龟币）用词区分，勿把房卡叫成金币。
- 若生成代码：UI 节点必须在 Canvas / UI_2D 层；复用项目 LobbyTheme 色板与现有组件习惯，勿擅自换一套紫黑霓虹皮肤。

【字号参考（720 逻辑像素）】
- 标题 24～28；正文 14～16；辅助 12～14；最小不低于 12。

【交付前自检】
1. 是否按 720×1280 标注？
2. 关键控件是否在 720 安全宽内且上下有边距？
3. 背景是否可满屏延伸？
4. 是否避免了无必要的整屏高清大图与拉伸变形适配？
```

## 使用说明

| 场景 | 用法 |
| :--- | :--- |
| 出图 / Midjourney 等 | 正文 + 追加具体页面（如「登录页」「大厅游戏架」）与风格关键词 |
| 写 Cocos UI 代码 | 正文 +「输出 TypeScript，挂到 Canvas，使用 UITransform/Widget」 |
| Cursor Agent | 已由 `cocos-ui.mdc` 自动约束；复杂页面可再粘贴本提示词强化 |

## 与工程代码对应

| 约束 | 代码 |
| :--- | :--- |
| 720×1280 | `LobbyUIKit.ts` → `UI_DESIGN_WIDTH/HEIGHT` |
| FIXED_HEIGHT 满屏 | `ScreenFit.ts` → `applyScreenFit` / `getVisibleFrameSize` |
| Canvas 满屏背景 | `UICanvasHost.ts` → `FullBleedBg` + Widget 四边 0 |
| 内容安全区 | `LaunchAutoBuilder` / `LobbyAutoBuilder` 根节点 720×1280 |
