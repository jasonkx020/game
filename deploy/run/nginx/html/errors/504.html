网关超时

上游服务在限定时间内未返回响应。大屏素材上传、OTA 包分发或远程会话可能耗时较长。

  • 大文件请走 /files/ 或 MinIO :9002，并确认超时配置足够。
  • 租户网关已配置较长 proxy_read_timeout；若仍超时请检查磁盘与网络。
  • WebSocket（/ws/、/mqtt）长连接断开也会表现为 504。
